# 2026-04-21 — Phase 4 exit: Market hall + creator analytics

Phase 4 shipped. Members can now discover courses by walking the Market; creators get real stats on their courses.

## What shipped

### Market hall (Phaser)

- `/market` — image-backed 1536×1024 interior, walking avatar, one **stall** per published course in the caller's realm.
- Stalls show course title + creator name + lesson count. Enrolled courses have an emerald border; unenrolled are purple.
- Top-right **search HUD** (React overlay) hides non-matching stalls via `setVisible(false)` — no React re-render of the scene.
- Clicking a stall opens a **modal** with a `backdrop-blur-xl` over the Phaser canvas. Course hero, description, section tree, inline `is_preview = true` playback, Enrol button.
- URL is the single source of truth for modal state (`?course=<id>`), so `✕`, Escape, and backdrop clicks all close cleanly and browser back works.
- **Enrol stays in the Market.** Click Enrol → a "✓ Enrolled" banner appears, the footer swaps to **Keep browsing** + **Open in Academy**. No redirect, no router.refresh (which would tear down Phaser and reset the avatar).
- **Avatar position persists across reloads** via `localStorage['arcadia:market:avatar-pos:<memberId>']`, saved every 500 ms while moving + once on scene shutdown.

### Creator analytics

- `/dashboard/courses/[id]/analytics` — three stat cards:
  1. **Enrolments** — `count(*)` from `enrolments`.
  2. **Completion rate** — % of enrolled members with `completed = true` rows for every lesson.
  3. **Active this week** — distinct members with a `lesson_progress` update in the last 7 days.
- **Recent activity table** — last 10 lesson-progress events with member display name, lesson title, status badge, and timestamp.
- **Owner-only.** `fetchCourseAnalytics` re-verifies `course.creator_id === auth.uid()` via the anon client before any admin read. Non-owners get a 404.
- **Service-role read.** RLS correctly hides other members' `lesson_progress` rows from the anon path; the owner-verified admin client is the sanctioned aggregate surface for this one workflow.
- **Analytics pill** in the course editor header next to the Publish toggle.

### Migration

- `20260422000001_phase4_market_indexes.sql` — `courses_market_idx (realm_id, published, created_at desc)` + `lesson_progress_completed_idx (member_id, lesson_id) where completed = true`. Applied to prod same session.

### Other

- Home hub gained a third card: **Visit the Market** (three-column grid; members + creators both see it).
- `VideoLessonViewer` + `WrittenLessonViewer` gained a `previewOnly` prop that short-circuits all server-side progress writes.

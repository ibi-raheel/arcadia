# 2026-04-21 — Phase 5 exit: gamification + polish bundle

**MVP is feature-complete.** Phase 5 was the final planned phase in `/docs/mvp/phase-plan.md`. Everything the plan committed to ships and runs on prod.

## What closed out today

Gamification core (Steps 1–10) was live earlier on 2026-04-21 (see the separate `2026-04-21_phase-05-gamification-core.md` entry). This log covers the bundled-polish items that finished Phase 5:

### Step 13 — Stall enrolment counts

`/market` stall cards now render "N enrolled" with real data. The `get_enrolment_count(course_id)` SECURITY DEFINER RPC had shipped alongside the gamification migration — this commit just teaches the server component to call it per visible course, in parallel. Cards that previously hard-coded 0 now reflect reality without leaking other members' individual rows (RLS on `enrolments` still blocks the raw selects).

### Step 14 — Leaderboard display-name fallback

`memberships.display_name` is nullable in the DB; the Tavern's `LeaderboardPanel` was rendering empty rows for members who hadn't set one. New `resolveDisplayName()` helper falls back through a chain:

```
display_name (trimmed) → AVATAR_NAMES[avatar_id] → "Player"
```

Type widened to `display_name: string | null`; `avatar_id` added to the select. Realtime UPDATE payloads carry the full row so the subscription-side merge path works unchanged.

### Step 15 — Image-backed scene collider scaffold

New shared helper `components/game/scenes/shared/colliders.ts` exposes `spawnColliders(scene, rects)` — builds a Phaser Arcade `StaticGroup` from a `PixelRect[]` config. Each image-backed scene (Tavern / Academy / Market) now has:

- A `colliders: []` entry exported from its `layers.config.ts`.
- A conditional wire in `create()` that calls `spawnColliders` + attaches a collider against the avatar body — skipped cleanly when the array is empty.

**Ships empty on purpose.** Avatar still walks over all furniture until the user drops rectangles into the exported `TAVERN_COLLIDERS` / `ACADEMY_COLLIDERS` / `MARKET_COLLIDERS` arrays. When they do, collision activates without any code change.

## MVP surface (on prod)

- **`/`** — role-aware hub (World / Market / Dashboard).
- **`/world`** — Phaser iso world, Colyseus multiplayer, building entrances.
- **`/tavern`** — image-backed bar, chat with speech bubbles, live XP leaderboard.
- **`/academy`** — Phaser hall, podium per course, opens React viewer.
- **`/academy/[courseId]`** — YouTube + react-markdown viewer with resume + progress tracking.
- **`/market`** — Phaser stall hall, search HUD, stall modal with preview + enrol.
- **`/dashboard`** — creator course list (role-gated).
- **`/dashboard/courses/[id]`** — two-pane editor with drag-reorder + Markdown / YouTube lesson editors + publish toggle + Analytics pill.
- **`/dashboard/courses/[id]/analytics`** — enrolment count, completion rate, active-in-7d, recent-activity table.

Lesson completion anywhere in the Academy awards XP via DB trigger → level recomputes → banner animates → Colyseus `UPDATE_LEVEL` propagates → peer badges update.

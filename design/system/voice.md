# Voice — the lexicon

The scriptorium has its own words. We don't say "login" or "dashboard." Every piece of UI copy is a tiny act of worldbuilding.

Source: `reference/2026-04-23_v4.5-scriptorium-01-design-system.html` nav + field labels + byline.

## Canonical renames

| Instead of… | Say… | Notes |
|-------------|------|-------|
| Log in / Sign in | **doorway** | `02-login.html` |

| Creator dashboard | **host** | `03-creator-dashboard.html` — the creator is a host, not a merchant |

| Password | **the word that lets you in** | As a field label |
| Submit / Save | **seal it** | On a wax button |
| Enter / Continue | **step inside →** | With a right-arrow glyph |
| Cancel / Back | **set aside** | On a ghost button |

| User / Member | — | Use the role (scribe / keeper / wanderer) |
| Profile | the scribe's journal / the keeper's ledger | Pick by role |
| Notification | a letter has arrived | For dramatic notifications; use sparingly |
| Login successful | welcome in | Warm, not triumphant |
| Error | the ink ran | Then explain what actually happened, in plain language |

## Roles

Three role chips, each with its own vocabulary:

- **scribe** — creators, authors, teachers. Bronze dashed chip.
- **keeper** — staff, moderators, admins. Wax-red dashed chip.
- **wanderer** — members, learners, visitors. Verdigris dashed chip.

These are not gamification labels — they're what we CALL people. Use them in copy: "your scribes have sent 12 missives," "a keeper signed this lesson."

## Place names

Used in copy and nav:

- **the tavern** — live social space (Phase 2+)
- **the academy** — course hall / learning space
- **the market** — creator stalls, catalogue
- **the coworking** — focus / work-alongside space
- **the square** — outdoor hub
- **the scriptorium** — design/admin, writing, composing

## Tone rules

- **Lowercase nav.** All top-level tags are lowercase: `hub`, `doorway`, `host`, `the kit`.
- **Title case for page h2.** "A room by lamplight, built by hand." Not ALL CAPS.
- **Italic display** for headlines. The voice itself italicizes.
- **Caveat marginalia** for the warm little side-notes — always tilted, always in `--oxblood` or `--gilt`.
- **Tilde bookends** for handwritten asides: `~ every swatch, every seal, every scrawl ~`. Reserved for the Caveat font.
- **One em-dash maximum per sentence.** Don't stack.
- **Ampersands allowed** inside small-caps headers (`BRONZE &amp; WAX`). Not in body.
- **Numbers:** folio-tagged when ceremonial (`FOL · XVII`, `I.`, `II.`, `III.`); Arabic when counting things (`31 present`).

## Endnotes

Every major page should close with an endnote: one italic display sentence above a small handwritten attribution, separated by a dashed bronze hairline.

> an opinion kept by the scribe: a room is only as warm as its lantern and as quiet as its ink.
> — inscribed in the margin, folio xxvii

This is not decoration — it's the page saying goodbye.

## Never say

- "Welcome to [product]!"
- "Click here"
- "Congratulations!" / "Awesome!" / "Let's go!"
- "Oops!" / "Uh oh!"
- "You're all set"
- Emojis in copy.
- Marketing superlatives (best, fastest, easiest, revolutionary).

## Copy patterns by surface

- **`scroll-card`:** ceremonial, first-line drop cap, "the royal missive" voice.
- **`vellum-card`:** neutral body; can be plain functional copy with one marginal Caveat note.
- **`ledger-card`:** precise, tabular; use small-caps for column heads; no marginalia (clutter).
- **`envelope-card`:** short and heavy; one big number, one label. Don't write paragraphs on envelopes.
- **`journal-card`:** data-first, mono captions. Minimal prose.
- **`map-card`:** place names only. Let the map speak.

## Swap to CC0 if going to paid commercial use

Bensound's free license allows use with attribution but prohibits resale-of-music scenarios. If Arcadia ever charges for tent access or repackages the audio, swap to fully-CC0 sources:

- [Pixabay Audio](https://pixabay.com/music/) — CC0 / Pixabay license, no attribution required
- [FreePD.com](https://freepd.com/) — public domain
- [Free Music Archive](https://freemusicarchive.org/) — filter by CC0 / Public Domain

Drop replacements at the same filenames; no code change needed.
